# 🚀 My DSA Journey: From Zero to Interview-Ready

Hi! I’m an aspiring frontend / software developer from India.  
This repository documents my **Data Structures & Algorithms (DSA) journey**—publicly, honestly, and consistently.

For a long time, I focused only on building projects.  
They looked good, but I knew my **problem-solving skills** needed serious work for coding interviews and long-term growth.

This repo exists because I finally chose **discipline over procrastination**.

My goal is simple:
